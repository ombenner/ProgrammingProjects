# California Housing Price Prediction

A regression project comparing KNN, OLS (Linear Regression), Ridge, and Lasso to predict median house value from housing features in the California Housing dataset

## What this project does

- Loads and explores the California Housing dataset (built into scikit-learn)
- Visualizes the distribution of home values and feature correlations
- Trains and tunes four regression models:
  - K-Nearest Neighbors Regression (tuned over k)
  - Ordinary Least Squares (baseline linear regression)
  - Ridge Regression (tuned over alpha)
  - Lasso Regression (tuned over alpha)
- Compares model performance using R² on a held-out test set
- Visualizes how L1 (Lasso) vs L2 (Ridge) regularization affects coefficient magnitudes

## How to run it

Open `California_Housing_Regression.ipynb` in Google Colab or Jupyter. All dependencies (`scikit-learn`, `pandas`, `numpy`, `matplotlib`, `seaborn`) are standard and typically pre-installed in Colab

## Tools used

Python, pandas, scikit-learn, matplotlib, seaborn
